# Luigi's Italian Restaurant

Luigi's Italian Restaurant is a responsive single-page website created for the WEB 210 Web Design course at Wake Technical Community College.

## Project Features

- Responsive CSS-only navigation with a mobile hamburger menu
- Custom color palette and typography
- Responsive hero section with a background image
- Featured menu section with optimized images
- CSS image shaping and filter effects
- Responsive layouts using CSS media queries
- Semantic HTML and accessible navigation
- Alternative text for content images
- External CSS stylesheet

## Accessibility and Validation

The website was tested using the WAVE Web Accessibility Evaluation Tool and the W3C Markup Validation Service.

- WAVE: 0 errors, 0 contrast errors, and 0 alerts
- W3C HTML Validator: No errors

## Technologies

- HTML5
- CSS3
